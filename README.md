# Retrô Games

Aplicação de quebra-cabeças retrô com uma tela inicial para escolher entre os modos deslizante e tradicional (jigsaw). Cada jogo abre em uma tela própria, ajustada à altura disponível para evitar rolagem durante a partida.

Escolha um dos jogos no menu para começar. Use o botão **Jogos** no topo da tela para voltar ao menu.
